# 猫暴力 · 个人养猫分享与流浪动物保护科普网站

一个纯静态的个人小站：记录调皮美短「猫暴力」的日常照片，提供猫咪百科科普，分享新手养猫经验，也关注流浪动物保护。
无框架、无构建步骤，直接在浏览器中打开即可预览。

## 快速预览

- **方式一**：直接双击 `index.html`。
- **方式二**（推荐）：在 `stray-home` 目录下启动本地服务器：

```bash
cd stray-home
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## ✏️ 常见修改

### 改照片 / 加照片
1. 把新照片放入 `assets/cat/`（建议最长边 ≤1600px，可用 macOS 自带 `sips -Z 1600 xxx.jpg` 压缩）。
2. 编辑 `js/main.js` 顶部的 `PHOTOS` 数组：增删条目或改 `cap`（图注）、`alt`（无障碍描述）即可，
   照片墙与「我家猫」版块的精选瞬间都会自动同步。
3. 首屏大图与档案配图固定引用 `photo-6-portrait.jpg` 和 `photo-8-lean.jpg`，想换图直接替换同名文件
   （或同步修改 `index.html` 中对应的 `<img src>`）。

### 改猫咪档案 / 文案
- 档案表（名字、性别、年龄、品种、来历、性格）与小传在 `index.html` 的「我家猫」版块，直接编辑。
- 技巧卡片、FAQ、页脚文案同样都在 `index.html` 里，改完保存刷新即可。

### 改配色 / 字体
- 设计令牌集中在 `css/style.css` 顶部的 `:root` 变量中，改一处全局生效。
- 标题衬线字体通过 Google Fonts 加载 Noto Serif SC，离线时自动回退系统字体。

## 交互功能清单

- 吸顶导航平滑滚动 + 当前版块高亮；移动端汉堡菜单
- 照片墙：点击打开灯箱大图，支持左右按钮与键盘 ←/→ 翻页、Esc/点遮罩关闭
- 「我家猫」精选瞬间：与照片墙共用同一灯箱
- 猫咪百科：科普条目分类 Tab、猫语速查折叠卡、猫年龄换算器、品种图鉴按特点筛选
- 保护流浪动物：现状与行动科普、遇到流浪动物五步指引、领养前自测清单（进度条交互）
- 病症速查：9 类常见病症「识别 / 居家 / 就医」三级卡片（可按类别筛选）、平价药品参考、就医红线清单
  ⚠️ 健康内容仅供家庭应急参考，不构成医疗建议；人用药物给猫使用前先咨询剂量
- **助力点赞**：「为流浪动物助力」爱心按钮，真实累计计数（第三方 Abacus 服务，CORS 全开放）
- **访客统计**：页脚显示累计访问次数 + 独立访客设备数（近似，UV 用 localStorage 按设备去重）
- FAQ 手风琴、滚动渐显、返回顶部

## 计数服务说明

访问与助力计数使用免费公开服务 [Abacus](https://abacus.jasoncameron.dev/)（无需账号）：

- 命名空间 `maobaoli-v1`，键：`support`（助力）/ `pageviews`（访问次数）/ `visitors`（访客设备）
- 接口：`/hit/{ns}/{key}` 自增并返回总数；`/get/{ns}/{key}` 读取（键不存在返回 `{"error":"Key not found"}`，前端按 0 处理）
- 键名长度要求 3–64 字符；该服务无管理后台，如需清零只能更换键名或命名空间
- 仅记录点击/访问次数，不涉及个人身份信息
