# 猫暴力 · 个人养猫分享网站

一个纯静态的个人小站：记录调皮美短「猫暴力」的日常照片，并分享新手科学养猫的经验与技巧。
无框架、无构建步骤，直接在浏览器中打开即可预览。

## 快速预览

- **方式一**：直接双击 `index.html`。
- **方式二**（推荐）：在 `stray-home` 目录下启动本地服务器：

```bash
cd stray-home
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## ✏️ 常见修改

### 改照片 / 加照片
1. 把新照片放入 `assets/cat/`（建议最长边 ≤1600px，可用 macOS 自带 `sips -Z 1600 xxx.jpg` 压缩）。
2. 编辑 `js/main.js` 顶部的 `PHOTOS` 数组：增删条目或改 `cap`（图注）、`alt`（无障碍描述）即可，
   照片墙与「我家猫」版块的精选瞬间都会自动同步。
3. 首屏大图与档案配图固定引用 `photo-6-portrait.jpg` 和 `photo-8-lean.jpg`，想换图直接替换同名文件
   （或同步修改 `index.html` 中对应的 `<img src>`）。

### 改猫咪档案 / 文案
- 档案表（名字、性别、年龄、品种、来历、性格）与小传在 `index.html` 的「我家猫」版块，直接编辑。
- 技巧卡片、FAQ、页脚文案同样都在 `index.html` 里，改完保存刷新即可。

### 改配色 / 字体
- 设计令牌集中在 `css/style.css` 顶部的 `:root` 变量中，改一处全局生效。
- 标题衬线字体通过 Google Fonts 加载 Noto Serif SC，离线时自动回退系统字体。

## 交互功能清单

- 吸顶导航平滑滚动 + 当前版块高亮；移动端汉堡菜单
- 照片墙：点击打开灯箱大图，支持左右按钮与键盘 ←/→ 翻页、Esc/点遮罩关闭
- 「我家猫」精选瞬间：与照片墙共用同一灯箱
- FAQ 手风琴、滚动渐显、返回顶部

## 说明

- 本站为个人养猫分享网站：照片均为博主实拍，养猫内容为个人经验分享，不构成医疗建议。
- 联系方式、社交媒体等处统一以「待补充」占位，可自行填写。
- 无任何后端与数据收集，纯静态页面。
